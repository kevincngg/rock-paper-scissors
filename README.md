# rock-paper-scissors

A simple Rock Paper Scissors game built with JavaScript as part of The Odin Project.

The game is played entirely in the browser console. The player chooses rock, paper, or scissors, while the computer randomly selects its choice.

## Features

- Random computer choice
- User input using `prompt()`
- Case-insensitive player input
- Tracks the player and computer scores
- Plays five rounds
- Announces the winner of each round
- Announces the overall winner at the end of the game

## How to Play

1. Open the project in your browser.
2. Open the browser developer console.
3. Enter your choice when prompted:
   - `rock`
   - `paper`
   - `scissors`
4. The game will play five rounds.
5. Check the console to see the result of each round and the final winner.
